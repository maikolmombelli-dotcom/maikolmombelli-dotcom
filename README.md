### 🚀 Featured projects

**🐾 [CareVet](https://github.com/maikolmombelli-dotcom/carevet)** · *completed · team of 4, team leader & full-stack developer*

A full-stack management app for a veterinary practice: online booking, digital
prescriptions and invoices (server-generated PDFs), vaccination records with automatic
email reminders, role-based areas for vets, receptionists and pet owners, and real-time
updates over WebSocket. A REST API with 104 endpoints on a 24-entity MySQL data model.

`Java 21` `Spring Boot` `Spring Security · JWT` `MySQL` `React` `WebSocket` `JUnit 5`

**⚽ Fantasy Football Manager** · *in progress · personal project · private repo*

Management software for a real sixteen-team Fantacalcio keeper league (Serie A *Mantra*
ruleset). It turns a long, complex rulebook — contracts, loans, co-ownerships, stadiums
and a credit budget — into rules the software enforces. The engine has already replayed
and reconciled the league's entire first season; data ingestion and the web interface
are next.

`TypeScript` `Next.js` `PostgreSQL` `Prisma` `Docker` `Vitest · 3,000+ tests`
